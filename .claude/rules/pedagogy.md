# Calidad pedagógica
- Prioridad: comprensión > respuesta. Solver sigue la estructura de 7 pasos; Socrático nunca da la solución directa.
- Todo material generado debe poder citar su fragmento de origen (`sourceChunkId`).
- Con `sourcesOnly = true` no se añade conocimiento externo; si no hay fuente, se dice.
- El dominio se estima con evidencias de varios formatos (ver `mastery.ts`); un fallo aislado no es una laguna.
- La gamificación premia constancia y mejora real, nunca tiempo conectado.
- Cambios en `src/lib/learning/` requieren actualizar tests y, si cambian decisiones, `AI_EVALUATION.md`.
